# Memories

Memories is a **full-stack social media web application** where users can create, edit, like, and delete posts to share their memories.

The project is built using the **MERN stack (MongoDB, Express, React, Node.js)**.

---

## Tech Stack

**Frontend**
- React
- Redux
- Material UI
- Axios

**Backend**
- Node.js
- Express
- MongoDB (Mongoose)

---

## Features

- Create and share memories
- Edit and delete posts
- Like posts
- Image upload support
- Responsive UI
